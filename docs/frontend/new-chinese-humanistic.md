# 新中式人文风格改造

> 范围：仅 `book-vue` 前端（模板、样式、纯展示文案）。不改后端、接口、数据库与业务逻辑。

## 1. 设计命题

- **对象**：数字化书籍服务系统的馆员与读者。
- **页面任务**：让「查书、借阅、归还、管理」这件日常事务，拥有安静、可信、有书卷气的界面气质。
- **关键词**：宣纸、墨、朱砂、册页、印章、留白、克制。
- **不做**：不做古风游戏 UI，不堆龙凤祥云，不用大面积金色，不引入外部图片素材，不为了“中式”牺牲表格与表单的可读性。

## 2. 视觉基调

### 2.1 色彩

| Token | 色值 | 用途 |
| --- | --- | --- |
| 宣纸 `--paper` | `#F4EEE2` | 页面底色 |
| 素笺 `--paper-2` | `#FBF7EE` | 卡片、弹窗、输入框 |
| 陈纸 `--paper-3` | `#EFE7D8` | 侧栏、次级底色 |
| 墨 `--ink` | `#20241F` | 主文字、标题 |
| 淡墨 `--ink-2` | `#5C635B` | 次级文字、标签 |
| 远墨 `--ink-3` | `#8A8F86` | 辅助说明、页脚 |
| 朱砂 `--cinnabar` | `#A33B2B` | 主操作、强调、印章 |
| 朱砂暗 `--cinnabar-dark` | `#7E2C20` | 主按钮 hover |
| 黛青 `--dai` | `#2F4F49` | 次操作、成功、库存 |
| 竹青 `--bamboo` | `#7E9A83` | 轻提示、辅助线 |
| 藤黄 `--gold` | `#B08A4A` | 细分隔线、装饰 |
| 界栏 `--line` | `#D9CDB8` | 边框、表格横线 |

### 2.2 字体

| 角色 | 字体栈 | 使用位置 |
| --- | --- | --- |
| 标题 / 展示 | `"Source Han Serif SC", "Noto Serif SC", "Songti SC", "STSong", "SimSun", serif` | 品牌名、页面标题、表头、弹窗标题 |
| 正文 / 控件 | `"Source Han Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif` | 表格内容、表单、按钮 |
| 题跋 / 点缀 | `"KaiTi", "STKaiti", "Kaiti SC", serif` | 对联、印章、引文 |

不引入在线字体，全部使用系统字体，保证离线可用。

### 2.3 材质与装饰

- 宣纸纹理：极淡的横向纤维 + 两处柔和晕染，用 CSS 渐变实现，不使用图片。
- 界栏：表格与卡片使用 1px 细线，重点位置用双线或 2px 墨线。
- 印章：朱砂色方框 + 楷体字，轻微旋转，低透明度；作为签名元素，出现在登录卷轴与每个内容页右下角。
- 留白：内容区四周至少 24px，表格行高不低于 44px。

## 3. 版式

### 3.1 登录页

```
┌──────────────────────────────────────────────┐
│  远山 / 淡日（CSS 水墨）        连接每一本书 │
│                                 服务每一位读者 │
│                    ┌──────────────┐          │
│                    │  ┌──卷轴杆──┐ │          │
│                    │  │   阅印   │ │          │
│                    │  │ 系统名   │ │          │
│                    │  │ 用户名   │ │          │
│                    │  │ 密码     │ │          │
│                    │  │ 登录 重置│ │          │
│                    │  └──────────┘ │          │
│                    └──────────────┘          │
│                       静心 · 阅世 · 知书      │
└──────────────────────────────────────────────┘
```

- 背景：宣纸底 + CSS 水墨远山 + 淡朱砂日轮。
- 主体：一张悬挂卷轴卡片，上下各一根木色卷杆，右上角“阅”字印章。
- 左侧竖排对联（宽屏显示，窄屏隐藏）。

### 3.2 主框架

```
┌──────────────────────────────────────────────┐
│ [书] 数字化书籍服务系统      admin（管理员） 更多 │
├────────────┬─────────────────────────────────┤
│ 收         │ 首页 › 书籍数据中心 › 书籍列表   │
│ 书籍数据中心│ ┌─────────────────────────────┐ │
│   书籍列表  │ │ 搜索 / 新增 / 批量上传       │ │
│ 书籍借阅服务│ │ 表头 ─────────────────────  │ │
│ 系统管理    │ │ 行   行   行   行            │ │
│            │ └─────────────────────────────┘ │
│            │                        [阅] 印章 │
└────────────┴─────────────────────────────────┘
```

- 顶栏：宣纸底、墨色字，左侧“书”字印章代替卡通 logo；品牌名用宋体，副标题用极小号字距。
- 侧栏：陈纸底色，像书脊；菜单激活项用朱砂左侧竖线 + 淡朱砂底。
- 内容：包在“册页”卡片中，细边框、轻阴影、右下角小印章。
- 页脚：远墨色小字，保留版权信息。

### 3.3 内容页

- 面包屑：宋体，末级为墨色加粗，其余淡墨。
- 工具行：搜索按钮用黛青，新增/导出用朱砂，次要操作用墨线描边。
- 表格：去掉斑马纹与粗网格，改为横向界栏；表头宋体、字距加宽；序号列朱砂，库存列黛青。
- 弹窗：素笺底，顶部一道朱砂细线，标题宋体。
- 分页：透明底、细边框，当前页朱砂。

## 4. 签名元素：一册一印

每个内容页右下角有一枚低透明度的朱砂“阅”印，登录卷轴右上角一枚完整的“阅”印。它承担两个作用：一是把“书籍”这件事变成可感知的物件，二是给所有页面一个统一的落款。除此之外不再增加装饰。

## 5. 动效

- 页面进入：内容册页 240ms 淡入并上移 6px。
- 按钮 / 链接：150ms 颜色与位移过渡。
- 表格行 hover：淡朱砂底色。
- 尊重 `prefers-reduced-motion`，关闭位移动画。
